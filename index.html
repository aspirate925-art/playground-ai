처음 값은 계획서의 예시 기준입니다(운동장 80·140명, 중정마당 20·40명). 실제 데이터를 보고 팀이 정한 기준으로 바꾸세요.

3. 마이크로비트

연결 안 됨

아직 보낸 값이 없습니다.

사용 순서
  1. 크롬 브라우저(노트북 또는 안드로이드 태블릿)에서 이 파일을 엽니다. 인터넷 연결이 필요합니다(AI 모델을 불러옴). 아이폰·아이패드는 웹 블루투스를 지원하지 않습니다.
  2. 마이크로비트 A에 아래 'A 코드'를 넣습니다. 메이크코드 프로젝트 설정에서 누구나 블루투스로 연결(No Pairing Required)을 꼭 켭니다.
  3. 카메라를 고르고 시작을 누릅니다. 창가처럼 높은 곳에서 운동장 전체가 보이게 고정합니다.
  4. 블루투스 연결을 눌러 마이크로비트 A를 고릅니다(이름: BBC micro:bit [다섯 글자]).
  5. 단계가 바뀌면 마이크로비트로 low, mid, high가 갑니다. 멈추면 stop이 갑니다. 모든 메시지 끝에는 줄바꿈이 붙습니다.
  6. 직접 센 인원을 입력하고 지금 기록하기를 눌러 AI와 비교합니다. 기록은 CSV로 내려받습니다.

개인정보: 영상은 이 기기 안에서만 분석되고 저장되거나 전송되지 않습니다. 촬영 전에 학교의 허락을 받고, 얼굴을 알아볼 수 없도록 멀리서 비추세요.

마이크로비트 A 코드 (블루투스로 받아서 핀으로 전달)

메이크코드 → 확장 → bluetooth 추가 → 'JavaScript' 탭에 붙여 넣은 뒤 '블록'으로 바꿔 보세요. 블루투스 확장을 넣으면 라디오는 쓸 수 없어서 B가 따로 필요합니다. A의 P0·P1·GND를 B의 P0·P1·GND에 점퍼선으로 연결합니다.

let data = ""
bluetooth.startUartService()
basic.showIcon(IconNames.SmallDiamond)
bluetooth.onBluetoothConnected(function () {
    basic.showIcon(IconNames.Yes)
})
bluetooth.onBluetoothDisconnected(function () {
    basic.showIcon(IconNames.No)
})
bluetooth.onUartDataReceived(serial.delimiters(Delimiters.NewLine), function () {
    data = bluetooth.uartReadUntil(serial.delimiters(Delimiters.NewLine))
    if (data == "low") {
        pins.digitalWritePin(DigitalPin.P0, 0)
        pins.digitalWritePin(DigitalPin.P1, 0)
        basic.showIcon(IconNames.Happy)
    } else if (data == "mid") {
        pins.digitalWritePin(DigitalPin.P0, 1)
        pins.digitalWritePin(DigitalPin.P1, 0)
        basic.showIcon(IconNames.Meh)
    } else if (data == "high") {
        pins.digitalWritePin(DigitalPin.P0, 0)
        pins.digitalWritePin(DigitalPin.P1, 1)
        basic.showIcon(IconNames.Surprised)
    } else if (data == "stop") {
        basic.clearScreen()
    }
})
마이크로비트 B 코드 (핀으로 받아서 라디오로 보내기) 
radio.setGroup(7)
let level = 0
basic.forever(function () {
    level = 0
    if (pins.digitalReadPin(DigitalPin.P0) == 1) {
        level = 1
    }
    if (pins.digitalReadPin(DigitalPin.P1) == 1) {
        level = 2
    }
    radio.sendNumber(level)
    basic.showNumber(level)
    basic.pause(1000)
})
마이크로비트 C 코드 (운동장 입구 신호등) 
radio.setGroup(7)
let lastTime = 0
radio.onReceivedNumber(function (receivedNumber) {
    lastTime = input.runningTime()
    if (receivedNumber == 0) {
        basic.showIcon(IconNames.Happy)
    } else if (receivedNumber == 1) {
        basic.showIcon(IconNames.Meh)
    } else if (receivedNumber == 2) {
        basic.showIcon(IconNames.No)
        music.playTone(523, music.beat(BeatFraction.Quarter))
    }
})
basic.forever(function () {
    if (input.runningTime() - lastTime > 10000) {
        basic.showIcon(IconNames.Confused)
    }
    basic.pause(1000)
})

B와 C는 같은 라디오 그룹(7)이어야 합니다. 10초 넘게 신호가 없으면 C에 '?' 표정이 나옵니다. 창가에서 운동장 입구까지 신호가 닿는지 꼭 시험하세요.
